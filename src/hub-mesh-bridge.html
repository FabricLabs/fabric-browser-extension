Fabric Passport — Hub background mesh

With the @fabric/passport extension installed, this page registers long-lived WebRTC signaling (offscreen document + service worker) for this Hub origin. You can close this tab; the extension keeps the signaling WebSocket until you unregister or disable the extension.

Same-origin check: hubAddress must match this page’s origin (scheme + host + port in the URL bar). Examples: http://127.0.0.1:8080/hub-mesh-bridge.html on a local Hub, or the same origin as the static test server (default port 3003; Playwright UI tests often use 3044 — see playwright.config.ts).
